# 极简对话界面验收

日期：2026-10-18。需求：整体UI简化，主区以对话为主，旁侧介绍功能，上传/表单随原业务流程出现。用户明确选择“对话为主，按需出现表单”。

## 实现

- 首页保留需求输入、五类业务及自动识别、三阶段进度、旁侧功能说明。首次发送/上传/创建样本时自动建会话。
- 理赔先材料，贷款先材料或显式确认的自填模式；完整表单随后展开。授权阶段折叠已确认信息，独立按钮开始评估，仍检查本地编辑是否确认。
- 历史、会话、服务、运行编号、事件及异常恢复移入“历史与设置”。未知请求在主区保留恢复提示并锁定重复提交。
- 结果保留来源模式、限制和下一步，引用和原始事实折叠，报告下载位于结果区。新对话保留身份与历史，取消附件选择并清除本地证据展示。
- 保留金额字符串、逐项确认、贷款授权/撤销、运行版本检查、复制后重新确认与授权。未更改后端业务规则和外部工具实现。

## 本轮代码验证

独立Windows/Python3.13环境执行：

```powershell
python -m pytest -q tests/test_scaffold.py tests/test_api_workflow.py tests/test_delivery_api.py tests/test_loan_copy.py
node --test tests/browser/workflow-view.test.cjs
```

最终结果：**42个API/契约与交付回归通过，21.82秒；5个Node展示状态测试通过，152.994ms**。这是针对本次界面的相关回归子集，不是重新执行此前219项完整后端套件。

新增Node测试先在未实现映射时出现5项断言失败，完成实现后通过，覆盖初始/澄清、上传、自填提示、独立授权、部分/取消结果和未知请求恢复。

`web/app.js`、`web/workflow-view.js`、两份旧浏览器脚本及新的`ui-controls.cjs`均通过Node语法检查。100个HTML ID唯一，92个字面量脚本ID引用均存在。首页、health及新增静态脚本HTTP200，`git diff --check`通过。

旧Playwright脚本已调整为显式揭示原生侧栏/折叠区域，并将授权后的提交改为独立评估按钮；本轮只检查其语法，未声称整套脚本已运行。此前独立浏览器启动环境失败没有被计为通过。本轮实际交互使用Codex应用内浏览器完成。

## 应用内浏览器实际操作

使用本机8000服务、合成资料；服务配置DeepSeek、stdio MCP及SQLite。配置状态不等于每一次输出都由模型生成；以下记录以页面实际业务结果为证据。

| 检查 | 实际观察 |
|---|---|
| 新首页 | 无需手动建会话即可发送；资料、技术信息默认折叠；主区与旁侧介绍分开 |
| 默认自动识别 | “合成测试：我想咨询基金投资，需要先提供哪些信息？”识别为投资咨询，展开画像表单，入口仍为自动识别 |
| 自填贷款 | 初始只显示资料来源；显式选择并确认自填后展开完整表单；7项确认后单独等待授权 |
| 编辑门槛 | 授权后改申请金额，评估按钮被本地校验拦截，提示重新勾选；折叠表单可展开复核 |
| 模拟评估 | 申请12000元/12个月、收入8000元、月偿债1000元，返回mock，月均本金1000.00元、偿债比例25%，保留自填未经核验标识 |
| 复制、撤销与取消 | 复制后确认数0、未授权；窄屏授权可撤销，等待运行可取消并保留历史 |
| 贷款材料 | 合成收入PDF首次附加后预填月收入/负债/就业状态；直接出现证据入口与3个提取字段，确认数0，无需刷新 |
| 理赔 | 无附件只引导上传；显式创建并选取合成保单，继续后提取4字段，原文/页码/置信度可展开；逐项确认后完成mock条款初筛 |
| 年度个税 | 全年收入额120000元、额外扣除30000元，结果900.00元、应纳税所得额30000元、税率3%；官方政策引用可展开，Markdown实际下载成功 |
| 投资部分结果 | 510300/511990混合请求，显示部分结果；保留510300历史指标及类别模板，明确511990未入库；不补造缺失指标 |
| 历史 | 打开侧栏自动读取历史；选记录成功后侧栏关闭，主区显示相应结果；新对话后同一身份历史仍保留 |
| 网络异常 | 临时将独立测试标签设为离线，业务POST失败后主区恢复入口可见，发送/新对话锁定；恢复网络后只读定位返回404，原锁保留，不自动重发 |
| 窄屏 | 实际innerWidth=390，页面内容宽375（另含滚动条），无横向溢出；表单单列，已确认字段折叠、授权、撤销、取消可操作；Escape可关闭原生侧栏 |
| 桌面与错误 | 默认1280px视口检查首页与结果；主流程测试标签错误日志为空，刻意断网的资源错误不算正常流程无错误证据 |

独立静态审查及补充改动复审均未发现有证据的重要回归。审查未代替本轮实际交互。
