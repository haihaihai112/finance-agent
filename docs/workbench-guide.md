# 中文工作台操作指南

工作台由普通 HTML、CSS 和 JavaScript 组成，无 Node 构建步骤。通过应用服务访问首页；页面和 API 必须使用同一个服务来源，不能直接双击 HTML 文件运行。浏览器需要支持 fetch、sessionStorage 和 crypto.randomUUID，建议使用当前版 Chrome、Edge 或 Firefox。

## 会话与资料

1. 点击“建立新会话”。服务端返回会话、用户与 Bearer Token，浏览器仅在当前标签页的 sessionStorage 中保留凭据、运行 ID 和意图。
2. 如果已有凭据，展开“恢复已有会话”，填写会话 ID 与 Token。输入凭据不会绕过服务端鉴权，私有请求仍须验证身份。
3. 选择 PDF、PNG 或 JPEG，点击“上传并提取”。支持多份文件；每份文件分别上传并调用提取接口，服务端复用已有提取缓存。图片 OCR 可用性以服务端返回为准。
4. 上传成功的资料默认作为下一次请求的附件。取消“附加到业务”可从下一次请求中排除资料；此操作不会删除服务端文件。
5. 点击“查看提取”核对字段值、原文、文档 ID、页码、置信度、坐标和服务端确认状态。置信度不代表经验证的准确率；未提取字段时可手工填写表单。

刷新页面只读取已有运行，不自动发起业务。文件内容和解析原文不写入浏览器持久存储。页面按服务端返回的 `document_ids` 读取资料信息与提取证据，恢复资料列表。已结束的贷款可以通过“复制为新申请”复用资料、证据和表单值。清除此标签页会话不会删除服务端数据；关闭标签页通常会清除 sessionStorage。

演示资料只在明确点击“创建本会话演示样本”后创建。按钮显示合成保单并加入可选资料列表，但不默认附加演示文件、不提交业务、不授权。需自行勾选样本，再核对提取和表单。

## 发起业务与确认

默认使用“自动识别”入口模式，直接描述问题，前端不指定意图；服务端路由根据自然语言识别五类业务之一。也可手动选择投资、理赔、贷款、政策 / 税务或其他，再点击“发起业务”。“自动识别”是入口模式，不是第六个业务意图。

系统返回实际业务意图、运行 ID、状态版本、等待原因、问题及业务表单，页面按服务端返回的实际意图展示。等待中不能通过入口选择器切换当前运行；多意图或不明确的问题会进入澄清，请在聊天区说明先处理哪类业务。等待原因是流程状态，不是新增业务意图。

在聊天区发送补答可补充自然语言说明或上传后的材料；结构化字段须在业务表单中逐项核对并勾选，再点击“提交已确认字段并继续”。金融字段不会自动确认。修改字段会清除对应勾选；刷新后只有服务端已经确认的字段显示为已确认。已填写但未勾选的字段会阻止表单提交，可选字段不需要时应清空。

金额显式输入为人民币元，提交结构为 `{amount: "1000.00", currency: "CNY"}`。页面保持金额字符串，不用 JavaScript 浮点数转换；不接受千位分隔符，最多两位小数。无负债、无偿债支出或无扣除时应明确填写 0；无现有资产可填写“无”，提交空列表。原文币种缺失或不是 CNY 时，页面提示先核对，不能仅凭勾选猜测换算。系统不提供汇率换算。

各业务关注点：

- **投资咨询**：确认地域、可投资金额、期限、风险、流动资金需求、负债、现有资产和基金代码。基金 / ETF 基金代码输入六位数字，多个代码用逗号或换行分隔。首版使用公开日频净值；数据时间以结果为准，不表示实时行情，策略模板不预测收益。
- **理赔申请**：先上传保单、版本与出险材料。确认保单号、条款版本、出险类型和日期；填写的保费、保险金额、险种、保险机构也须确认。服务端按当前用户查询历史保单，结果是初步筛查。
- **贷款申请**：先上传收入、负债等材料。确认申请人参考编号、金额、期限、月收入、月偿债支出与就业状态；额外填写的资产和负债等字段也须确认。遇到冲突时同时显示材料和用户输入证据，请明确填写正确值。
- **政策 / 税务**：确认地域和税年。年度试算另需居民身份、居民年度综合所得收入额、除 60000 元基本减除费用之外的年度扣除合计。收入额不是扣除后的应纳税所得额；不要用单月工资代替全年金额。非居民等超出首版的情形由服务端说明。
- **其他**：系统明确说明超出服务范围的问题。

## 授权、恢复与异常

贷款表单确认与征信授权分开。点击“明确授权本次模拟评估”只创建当前运行授权，随后再次点击提交确认表单才继续评估。未授权不能调用模拟征信 / 风控。点击“撤销授权”撤销服务端授权引用；历史结果仍是历史记录，不代表再次授权。页面不会把字段勾选当作授权，也不会跨新运行沿用授权。

贷款运行结束后，右侧显示“复制为新申请”。明确点击后，服务端创建新的等待确认运行，复制原材料、提取证据与表单值，清空全部字段确认和授权。重新核对金额、期限等字段并勾选确认，然后另行授权本次评估。右侧“原运行 ID”记录来源；“读取原运行历史结果”可查看原结论。复制和新评估不覆盖旧结果或旧授权记录。此流程适用于已完成、部分结果、失败或取消的贷款运行；未结束的贷款须先完成或取消。

身份编号、保单号、版本和就业状态拒绝纯空白或超过 128 字的值；保险机构、险种和出险类型限制为 256 字。就业状态仍为自由文本，不预设真实银行就业规则。

右侧可“刷新当前运行”，或填写运行 ID 后“读取并恢复”。恢复要求拥有当前运行的会话凭据。版本冲突（HTTP 409）会停止提交；先刷新最新版本，再重新核对并确认。不要用不同标签页同时编辑同一个运行。

网络异常、超时和工具错误会明确显示，不自动重复发送业务请求。新申请、继续和贷款复制先保存请求 ID 与操作类型到当前标签页的 sessionStorage；不保存消息、表单或文件内容。响应丢失后，在“请求异常恢复”点击“定位 / 刷新请求”，按 `GET /api/v1/requests/{request_id}` 定位并读取关联运行。刷新页面保留恢复入口；切换会话清除旧请求定位信息。未知请求只显示未找到，不自动重新发起业务。

请求 `completed` 仅表示该次 HTTP 操作已完成，业务运行仍可能 `waiting`；请求 `processing` 时显示状态，用户明确点击刷新。超过 5 分钟无更新才可点击“人工中断超时请求”；服务端再次校验资格，409 时停止并显示反馈。中断会撤销本次授权并防止迟到结果覆盖，之后只读取运行，不自动重试工具。鉴权异常时恢复正确会话；OCR 不可用时检查本地模型或补充带文本层的 PDF。

健康状态区显示服务阶段、模型模式及存储信息。DeepSeek Key 配置在服务端，页面不收集模型密钥；未配置时使用规则处理。健康接口可响应不等于外部行情、OCR、数据库等所有工具都可用。

## 结果核对

“历史运行”点击“刷新历史”读取当前用户运行，最新创建的记录在前，使用“上一页 / 下一页”翻页；选择记录只读取已有运行及其材料，材料读取失败时保留原编辑内容。服务端 `GET /api/v1/runs` 返回数组，支持 `limit=1..100`（默认 50）和 `offset>=0`。切换记录后应重新核对当前运行 ID 和版本。

“事件与报告”点击“读取运行事件”访问 `GET /api/v1/runs/{id}/events`，页面展示中文事件类型和 UTC 时间，不直接展示内部事件 payload。点击“下载 JSON 报告”或“下载 Markdown 报告”访问 `GET /api/v1/runs/{id}/export?format=json|markdown`，下载请求使用 Bearer 请求头，Token 不进入 URL。报告包含运行及父运行 ID、意图、状态、版本、结果和数据范围；结果保留事实、引用和限制，不导出内部状态、表单、凭据或授权引用。没有结果时返回 409，等待中的运行若已有部分结果也可导出。历史、事件和下载均验证当前用户归属，不执行模型或 MCP。

结果默认显示中文摘要：贷款的模拟分类、仅本金月摊与偿债比例；税务的年度税额、应纳税所得额与适用税率；投资的类别配置金额、比例、基金历史净值变化和观测最大回撤；理赔的条款初筛与出险日期。原始结构化事实默认折叠，可点击“展开原始结构化事实（核验）”查看，便于面试演示与数值核对。页面只格式化服务端数值，不重算金融事实；百分比用十进制字符串移位展示。

理赔初筛分别显示“可能符合条款，需机构审核”“出险日期不在保障期内”“所提供条款包含除外情形”“条款需人工审核”。是否在保障期内直接读取 `within_effective_dates`，没有此字段时显示“未提供”。

引用原文、来源 ID、文档页码、政策有效日期、检索时间、限制和下一步继续显示。`real` 表示真实来源，`redacted` 表示脱敏来源，`mock` 表示模拟数据。模拟征信结果不代表银行审批；合成保单也不代表真实保单。请根据来源、数据时间和限制判断结果适用性。

外部模型文本、文件原文和引用均以纯文本显示。引用链接仅允许 http / https，其他 URI 不提供可点击入口。高级面板可查看服务端响应 JSON，仅用于查看，通常无需手写 JSON。

## 已执行的工作台验证

2026-10-13 使用项目 Python 虚拟环境、规则模式和 Playwright 驱动真实 Edge 浏览器完成联调。最终复测使用 `stdio` MCP 跨进程模式，覆盖五意图；理赔 / 贷款得到模拟结果，投资取得基金日频净值与引用，税务取得政策引用和年度试算。税务合成样例为收入额 120000 元、其他年度扣除 0 元，年度税额 3480 元。

另外验证了显式创建演示材料、多材料上传与文本 PDF 提取、OCR 字段不默认确认、未确认表单不发送恢复请求、编辑后清除确认、表单确认不自动授权、授权与撤销分开、完成后仍可撤销且刷新不恢复旧授权、同会话刷新恢复、并发版本冲突停止提交及刷新后恢复。桌面和 390px 手机页面截图已检查，无横向溢出或浏览器脚本错误。

这些验证使用合成材料与指定样例，不代表真实审批、投资收益、OCR 准确率或生产性能验证。
