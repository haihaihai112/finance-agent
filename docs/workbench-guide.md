# 金融助手使用指南

本界面以对话为主：左侧描述需求和完成操作，右侧介绍功能并提示下一步。手机宽度下，功能介绍位于主操作下方。访问应用服务首页，不要直接双击HTML文件。

## 从一句话开始

1. 默认“自动识别”，直接描述问题并点击“发送”。也可先选择投资、理赔、贷款、政策 / 税务或其他。
2. 首次发送、上传或创建演示资料时自动建立本标签页会话，无需先配置身份。系统不会自动填写财务数值。
3. 涉及多项业务时先澄清办理顺序；自动识别是入口模式，不是第六类意图。
4. “新对话”退出当前编辑，清空当前聊天和附件勾选，保留同一身份及服务端历史。旧业务仍可从“历史与设置”恢复；需结束等待业务时点击“取消本次办理”。

顶部三个阶段对应真实工作流：描述需求 → 补充与确认 → 查看结果。右侧“当前引导”随服务端状态变化。

## 上传与字段确认

“添加或管理资料”平时折叠，理赔或材料模式贷款需要时展开。选择PDF、PNG或JPEG后点击“上传并提取”；支持多文件。上传成功的资料默认勾选，勾选仅表示附加到下一次请求，不代表确认提取结果。

等待上传时，选择资料后点击“使用已选资料继续”。系统提取并预填字段，完整业务表单随后出现。可展开“核对材料原文与提取结果”，查看字段值、原文、文档、页码、置信度、坐标与服务端确认状态。“查看提取”会主动打开证据区。置信度不等于经过验证的准确率。

“使用演示资料”需主动展开并点击“创建演示资料”。模拟保单及收入证明不会默认勾选、提交或授权；演示净值快照来自真实公开来源，但不是实时交易报价。

逐项核对填写内容并勾选，再点击“确认并继续”。金额以人民币元填写，最多两位小数，不含千位分隔符；前端保持字符串，不用浮点数重算金额。没有负债、偿债支出或其他扣除时明确填0；没有现有资产填“无”。修改字段会取消对应确认，聊天补答不能替代字段勾选。可选字段不提交时留空。

原文币种缺失或不是CNY时需核对，不能猜测换算；系统不提供汇率换算。

## 四类业务流程

- **投资咨询**：补齐地域、金额、期限、风险、现金需求、负债、现有资产与六位基金代码，确认后查询日频净值及历史指标。演示代码510300仅为样例。代码数据不全会保留可用部分并提示缺失，不编造价格或收益。
- **理赔申请**：先上传保单及出险凭证，再核对保单号、条款版本、出险类型与日期及已填金额。按当前用户查询历史保单，输出条款初筛，最终赔付由机构审核。演示保单是模拟资料。
- **贷款申请**：可上传收入、负债等材料；没有材料时，在资料来源明确选择并确认“自填试算（未经材料核验）”，随后填写完整申请。必填主体编号、申请金额、期限、月收入、月偿债支出与就业状态。冲突时核对材料和用户输入证据，明确填写正确值。
- **政策 / 税务**：确认地域、税年、居民身份、居民年度综合所得收入额及除60000元基本减除费用之外的年度扣除。不要用单月工资或扣除后所得替代全年收入额。首版不支持年终奖单独计税或非居民计算。

其他问题由范围外响应处理，不新增金融业务。

## 贷款独立授权

字段确认后，已确认表单折叠为“查看或修改已确认信息”，并单独显示本次模拟评估授权。点击“授权本次模拟评估”只创建授权，再点“开始模拟评估”才继续。评估前会重新检查表单；授权后修改金额仍须重新勾选。

结果明确标为模拟规则；自填来源保留“未经材料核验”。“撤销授权”可在结果之后使用，历史结果不会因此变成新的有效授权。

完成、部分结果、失败或取消后可“复制为新申请”。复制保留字段值及资料，全部确认和授权清空，必须重新核对并单独授权。投资、理赔和税务也支持复制后重新确认；原结果保留。父运行信息位于“历史与设置 → 运行信息与恢复”。

## 结果、历史与报告

结果主区显示来源模式、中文摘要、使用限制和下一步；“查看来源与引用”和原始结构化事实默认折叠。结果里的real表示真实来源，redacted表示脱敏来源，mock表示模拟数据。标签不代表金融准确率或机构认可。

“下载报告”为Markdown，“下载JSON”保留结构化内容，均需当前用户鉴权。报告包含事实、引用、限制和运行信息，不导出内部表单、凭据或授权引用；Token不出现在URL中。

“历史与设置”打开即读取当前身份历史，可翻页并选择运行；成功恢复后自动回到主区。读取资料失败会保留原编辑，避免把不同运行与附件混用。运行事件、版本/编号、会话恢复和服务详情也在此侧栏。

## 请求恢复与会话

网络异常时不自动重复业务请求。主区显示“查看请求”，打开后按已保存的请求ID只读定位。结果未知期间，“发送”和“新对话”等操作锁定；刷新不会自动重新提交。请求completed仅表示该HTTP操作完成，业务仍可能等待补充。

404不能排除迟到处理，不能据此自动解锁。核对历史后，仅原待定位ID真实返回404时可明确确认风险并解除本地锁定；解除不取消服务端请求，不自动重发，原编号保留供追查。processing超过5分钟无更新才可显式人工中断，由服务端再次校验资格。版本冲突须先刷新运行并重新核对。

会话设置中的“建立独立会话”切换身份；“新对话”不切换身份。浏览器仅在当前标签页sessionStorage保留凭据、运行及请求编号等元数据，不缓存材料正文。清除会话不删除服务端数据。恢复已有会话需要原会话ID和凭据，不绕过归属校验。

服务状态保留实际模型配置、存储和工具模式。健康接口可响应不代表全部外部工具可用；DeepSeek密钥只在服务端.env配置。
