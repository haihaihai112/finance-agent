# 个人项目本地验收清单

本页是可重复操作清单，实际执行结果见 [verification.md](verification.md)。通过本地样例不代表真实金融审批、投资收益、OCR准确率或生产性能。🧾

## Windows安装与启动

在项目根目录使用 Python >=3.11（当前干净验证环境为3.13）：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
Copy-Item .env.example .env
.\.venv\Scripts\python.exe scripts/doctor.py
.\.venv\Scripts\python.exe scripts/doctor.py --json --port 8000
.\scripts\start.ps1 -Port 8000
```

已有 `.env` 时不要覆盖。默认SQLite、规则降级与stdio MCP可演示；浏览器打开 http://127.0.0.1:8000 ，接口文档在 `/docs`。VS Code“运行任务”提供“金融项目：启动 / 离线诊断 / 代码验收”，使用本项目`.venv`。`start.ps1`遇到诊断阻断或服务非零退出会报告失败；Ctrl+C停止服务。端口占用时选其他端口。启动会初始化业务数据库，诊断不会。

诊断的 `blocking` 项必须处理；`unconfigured` 表示外部模型未配置，规则模式仍可用；`optional` 项说明缺少.env或图片/扫描OCR支持，不阻断文本PDF和核心业务。检查默认RapidOCR三份ONNX文件存在，不初始化推理、不下载模型；可用性还须用实际材料验证。所有诊断均离线只读，不输出数据库URL、密钥、Token、授权引用或原始异常信息。

## 五业务操作与预期

先“建立新会话”，再“导入演示资料”（按钮“创建本会话演示样本”）。演示资料不会自动附加，按需勾选；PDF文字层优先提取，扫描图片走ONNX推理。应用上传限制默认20MiB，可通过服务设置改变。每个提取字段核对值、币种、页码、原文、坐标与置信度，再逐项确认；置信度不能作为已测准确率。

| 业务 | 输入样例及操作 | 可验收结果及边界 |
|---|---|---|
| 投资 | “我想做基金投资规划”；CNY金额100000.00、12个月、中风险、现金需求10000.00、负债0、现有资产无、地域中国大陆、基金510300；逐项确认 | 类别配置、历史日频净值指标、来源与采集时间。数据过期时明确不可用并提示更新；不保证收益、不称实时行情 |
| 理赔 | 附加演示保单；保单号DEMO-POLICY-001、版本demo-v1、hospitalization、2026-10-01；逐项确认 | 当前用户历史条款与出险日期初筛，显示来源及mock演示标记，不等同保险机构决定 |
| 贷款 | 附加收入PDF；申请人DEMO-APPLICANT、申请金额12000.00、12个月、月收入10000.00、月偿债支出0、就业状态在职；核对材料冲突并确认，明确授权本次模拟评估，再继续 | 模拟风险类别、规则/金额计算、引用与限制。字段确认不代替授权；撤销后不可再次沿用授权 |
| 政策/税务 | 中国大陆、2026年、居民、年度综合所得收入额120000.00、60000元外年度扣除0；逐项确认 | 应纳税所得额60000.00、年度税额3480.00、政策引用；未减预缴税额，不等于补退税，不支持非居民全套试算 |
| 其他 | 手动选择“其他”，询问“帮我写一首诗” | 明确服务边界，不生成虚构金融事实 |

自动识别是入口模式而非第六意图；多业务问题先澄清，等待是状态。无DeepSeek密钥时展示规则降级。金额保持Decimal/字符串，输入不使用千位分隔符、最多两位小数、币种CNY。金融字段必须用户确认，缺失和冲突须明确补充。

## 历史、报告与异常恢复

1. 创建多个运行，点击“刷新历史”，检查最新创建在前、上一页/下一页以及选择历史记录；只可读取本用户数据。选择后材料加载失败应保留原编辑内容。接口`GET /api/v1/runs?limit=50&offset=0`仍返回数组。
2. 在已有运行点击“读取运行事件”，检查中文类型及UTC时间；不展示原始内部payload。点击“下载 JSON 报告 / 下载 Markdown 报告”，检查事实金额、引用、限制和数据范围一致。无结果运行返回409；只读操作不调用外部模型或工具，不导出表单、Token、密钥或授权引用。
3. 已结束贷款点击“复制为新申请”，检查原运行ID关联、原结果保留、材料与字段值复用、全部确认及授权清空；修改金额/期限后重新确认并重新授权。
4. 首次提交响应丢失或网络中断时，在“请求异常恢复”点击“定位 / 刷新请求”。sessionStorage仅保留请求ID和操作类型，不保留消息/表单/材料；刷新页面能找到恢复入口，切换会话清除旧定位元数据。请求completed可能对应waiting业务，禁止把请求完成当业务完成。
5. processing请求只显示状态与显式刷新，超过5分钟无更新才允许“人工中断超时请求”；409反馈须停止并解释。中断后只读取运行，不自动再次POST或重放工具。未知请求显示未找到。版本冲突时先刷新，再重新核对，不并发编辑同一运行。

请求定位`GET /api/v1/requests/{request_id}`、事件和导出均须Bearer鉴权且校验归属。不能通过修改run_id/request_id读取他人数据。导出接口为`GET /api/v1/runs/{id}/export?format=json|markdown`，鉴权放请求头，不放URL。

## 数据与外部验证限制

日频净值只覆盖受控公开基金/ETF来源。演示快照截至2026-10-13，来源、采集时间和新鲜度应以实际返回为准。更新可运行`.\.venv\Scripts\python.exe -m finance_agents.data_jobs.scheduler market --instruments 510300`；这是联网采集，非离线诊断。接口失败不能补造价格。政策为官方年度综合所得规则，网页变化只进入人工审核，不自动成为新法。来源证据见 [data-source-validation.md](data-source-validation.md)。

保单与信贷演示明确mock；公开来源real、脱敏来源redacted不等于业务审批已经真实完成。本地会话非企业SSO，运行数据保存在服务端，关闭标签页不删除数据。多进程使用数据库版本控制，不承诺生产容量。

MySQL真实服务目前未配置/未验证；按 [mysql.md](mysql.md) 配置专用数据库和权限，先备份旧库、停止并行实例，再单进程初始化。旧运行历史排序需要增量迁移创建时间字段；迁移后检查分页稳定性与归属。`MYSQL_TEST_URL`仅指向明确专用测试库，测试会写合成数据，不能指向真实业务库。记录实际测试结果后才说明MySQL链路验证通过。

DeepSeek真实付费调用目前未配置/未验证；在本地`.env`设置密钥、可用模型及LLM_ENABLED，重启后用最小业务验证真实调用、超时降级、事实保真和模型可用性。诊断不会调用接口，配置存在不算验证通过。不要在截图、报告、日志或源码包中包含凭据。

验收代码可执行`./scripts/verify.ps1`；正式浏览器复现见 [browser-verification.md](browser-verification.md) 和 `tests/browser/personal-delivery.cjs`。整体验收及安全打包由交付记录确认，不把本清单视为已执行证据。
