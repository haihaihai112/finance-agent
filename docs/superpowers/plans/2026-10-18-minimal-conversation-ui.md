# 极简对话界面：设计与实施记录

日期：2026-10-18。用户选择“对话为主，按需出现表单”。本次仅调整浏览器界面及相应验证与文档，保持原后端业务规则。

## 设计

- 以白色、深灰文字、低饱和绿色表达个人金融资料助手。色值：#ffffff / #24312e / #69736f / #e5e9e7 / #22634f / #f0f6f2。
- 使用系统中文字体 Microsoft YaHei UI / PingFang SC，标题30px，正文14px，功能说明12px。左对齐，不增加插图、统计卡片或装饰动画。
- 桌面为主对话区与右侧功能介绍；窄屏将功能介绍移到主操作下方。主流程仅三个实际阶段：描述需求、补充与确认、查看结果。
- 新对话保留同一身份及服务端历史，但清空当前聊天、取消附件选择和本地证据展示。独立会话切换保留在“历史与设置”内。

## 实施与约束

1. 重写HTML/CSS；首次发送、上传或创建演示资料时才建立会话，保留发送前已输入内容。
2. 将历史、会话、运行编号、事件、服务详情和请求恢复收至原生对话框；未知请求在主区保留明确恢复入口和提交锁。
3. 理赔先展开资料区；贷款先显示资料来源，显式确认自填后再显示完整字段。字段确认和独立授权仍由用户操作。
4. 授权阶段折叠已确认字段供复核；独立“开始模拟评估”按钮再次校验本地字段，修改金额后必须重新勾选。
5. 结果显示来源模式、摘要、限制与下一步；引用和原始事实默认折叠。保留报告下载、复制、取消与刷新。
6. 新增纯展示状态映射及Node测试，更新旧浏览器脚本的折叠控件定位；实际执行范围写入单独验收记录。

不更换OCR、不扩展税种，不改变日频净值、模拟保单/风控及MySQL真实服务待验证的边界。
