## 核验结论与修改

| 报告问题 | 核验事实 | 本次处理 |
|---|---|---|
| 税务无法计算 | 已有官方居民年度综合所得政策与确定性公式；年终奖单独计税超出首版，后续新请求又用了未接受的年度同义值 | 提前解释年终奖范围；接受明确年度同义值；格式示例；结束运行可复制修正。未增加奖金税法 |
| 行情无法查询 | 本机有510300的19条净值，报告混合请求的511990无记录；旧逻辑使整个请求失败 | 按代码判断缺失／过期／来源冲突／历史不足，保留可用记录与指标，返回PARTIAL并保留证据。全不可用仍不生成配置 |
| 中文OCR变成0 | 原测试PNG生成时未使用中文字体，图上已经是缺失字形；相同文件SHA256与上传记录吻合 | 保留RapidOCR ONNX，不把损坏源图归因为引擎准确率；正确显示中文的受控图片可提取金额，真实票据仍须验证 |
| 理赔没有保单 | 任意填写的保单号不在当前用户历史库；既有演示入口可显式导入模拟保单 | 补充“上传不等于历史入库”提示及演示指引，不虚构匹配记录 |
| 无材料贷款反复要求上传 | 原门禁符合上传流程，但没有个人试算入口 | 新增self_reported，必须结构化选择和确认；跳过OCR，不把字段包装为材料证据；逐项确认与独立授权后通过原MCP模拟评估 |
| 422格式不可理解 | 报告为API测试；网页已有金额、列表与枚举控件，但API缺说明 | 响应新增field_hints，含标签、类型、帮助、例子；保留pending_fields兼容。422不回显原始值或任意非法字段名 |
| 失败后不能修改 | 原复制仅贷款可用；结束运行不能resume是状态保护 | 四金融意图支持复制，保留父运行、值与材料，清空确认/授权，不自动执行；明确取消等待运行与仅退出编辑的区别 |

## 网页QA清单

- 自填资料来源可选且无默认自填；编辑后确认重置；合成字段确认后停在授权；授权后结果/限制可见自填标识。
- 复制后保留父运行、清空确认与授权；取消等待运行会保留历史。
- 税务范围提示、已结束运行复制按钮；行情部分结果缺失提示。
- 检查材料模式与演示入口仍可用；不自动把样例填成用户财务事实。
- 反向场景：错误金额422不改变版本；未确认模式、旧授权、全部行情缺失均应阻断。

本机独立Chromium启动返回spawn UNKNOWN，未据此宣称本轮自动浏览器套件通过；改用应用内浏览器做实际交互。发现旧脚本缓存，HTML脚本URL增加版本以刷新加载。本轮具体完成项及最终检查结果见 docs/verification.md 最新段落；过去的Edge双宽度验收不替代本次新增功能验收。
