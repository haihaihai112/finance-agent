# 2026-10-13 审阅修订规格

来源：用户提供的《新建文本文档 (2).txt》。文档中的技术建议须由现有代码和测试核验。

1. 理赔初筛四种真实枚举显示中文；保障期字段实际为 `within_effective_dates`，保留这个契约。
2. 历史贷款可显式复制为新申请：复制材料、提取证据和表单值；清空所有确认和授权；保留旧运行及授权记录；新运行保存 `parent_run_id`。仅允许已结束的贷款运行复制，新运行必须重新确认、重新授权。幂等保护复制请求。
3. 请求表增加运行关联、状态与时间；登记请求和创建/更新运行共用事务；最终状态与响应共用事务。保留 CAS。中断可查询定位，不能自动重放外部金融工具。显式人工关闭请求必须设置合理的超时门槛，且以事务关闭运行，阻止迟到结果覆盖。
4. 身份、保单及业务字符串拒绝空白与过长值；支持范围未规定的就业状态不强设银行规则或枚举。直接 API 测试覆盖负向输入。
5. 锁按使用引用数回收；OCR 并发有界，缓存访问及文件操作在线程执行；给出可重复、有限的并发测量。不要声称生产性能达标。
6. 完善专用 MySQL 真实集成验收（API + stdio MCP + CAS 冲突 + 采集回滚）；DeepSeek 验收只发送合成文本，记录耗时/usage，未配置服务时明确未验证，不能以 mock 代替。
7. 建立本地 Git，忽略密钥、运行数据及中间材料；正式浏览器验收可配置 Playwright 路径/浏览器/URL，包含四种理赔显示与贷款复制再评估。更新文档及源码包。

全局约束：保持五意图、六 Agent、四 MCP；金融金额保持 Decimal/字符串；OCR 不越过确认；贷款规则与保单为 mock；中国大陆/CNY/基金日频净值/居民年度综合所得个税；不创建或发布 GitHub 仓库。
